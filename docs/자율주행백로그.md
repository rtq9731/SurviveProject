# 자율 주행 백로그

사용자 부재 중 AI가 자율적으로 수행할 수 있는 작업 목록. 2026-08-05 코드베이스 전수 조사 기반.

## 운영 규칙

1. **게이트 필수** — 모든 작업은 AI가 스스로 성공/실패를 판정할 수 있는 게이트를 갖는다. 게이트를 통과하지 못하면 완료 보고 대신 실패 보고를 한다. 사용자는 사후 보고만 받는다.
2. **충돌 금지** — 서로 충돌하지 않는 작업만 동시에 다룬다. 같은 파일·같은 씬·같은 Domain 폴더를 건드리는 작업은 병렬 배정하지 않고 순차 처리한다. 각 항목의 `영역` 태그가 겹치면 충돌로 간주한다.
3. **병렬 인프라** — `E:\SurviveProjectClones\A·B·C` 클론 리포지토리에서 각각 별도 Unity 인스턴스로 uloop를 사용한다. 각 클론의 헤드 에이전트는 Opus 5.0 권장.
4. **회수 방식** — 클론에서 완료한 작업은 브랜치/커밋으로 본 리포지토리(`E:\SurviveProject`)에 회수한다. 커밋 메시지는 기존 규약(한국어 서술형, 무엇을 왜)을 따른다.
5. **금지 구역** — 서드파티 에셋(`Feel`, `polyperfect`, `Stylized Water`, `Unvik_3D`, `TextMesh Pro`), 자동 생성 코드(`PlayerInputActions.cs`), 미커밋 상태의 씬/프로젝트 설정(`TestScene.unity`, `EditorSettings.asset`, `TimeManager.asset`, `ChosunGu SDF.asset`)은 건드리지 않는다.

## 공통 게이트 절차

모든 작업은 최소한 다음을 순서대로 통과해야 완료로 간주한다.

1. `uloop-clear-console` → `uloop-compile` — 에러 0, 신규 경고 0
2. `uloop-run-tests` (EditMode) — 기준선 **123개 전부 통과** + 신규 테스트 통과
3. `Tools/Survive/참조 무결성 점검` — 끊긴 참조 0 (uloop-execute-dynamic-code로 메뉴 실행)
4. `Tools/Survive/아트 규칙 점검` — 위반 0 (아트 관련 파일을 건드린 경우)
5. 해당되는 경우 E2E 시나리오(`E2ERunner.Status` 폴링) 통과
6. `git diff` 검토 — 변경이 의도한 파일 범위를 벗어나지 않음

### 18. UI 프리팹 분리 (CvsUI 해체)
- **내용**: 단일 `CvsUI.prefab`을 패널 단위 중첩 프리팹으로 분리 — 최소 단위: HUD(바이탈·산소·배터리·힌트), PanelInven, CraftingPanel, StoragePanel, QuickSlotBar, ObjectivePanel, PanelDialog+SubtitleLine, BuildPlacementPrompt. 씬 오버라이드는 가능한 한 프리팹 안으로 흡수해 오버라이드 수를 최소화. 이후 UI 작업은 패널별 프리팹 파일만 건드리게 되어 병렬 충돌이 구조적으로 사라진다.
- **게이트**:
  1. 컴파일 + 참조 무결성 점검 0 + EditMode 123 유지
  2. `uloop-execute-dynamic-code`로 구조 검증 — 각 패널이 독립 프리팹 에셋으로 존재하고, 씬/CvsUI의 해당 노드가 프리팹 인스턴스이며, 씬 오버라이드 수가 분리 전보다 감소했음을 프로그램적으로 확인
  3. **분리 전/후 Game View 스크린샷 비교**(`uloop-screenshot`) — HUD·각 패널 열림 상태가 픽셀 수준에서 동일 구도
  4. 기존 E2E 전체 통과(UI 경유 시나리오 포함) + PlayMode 로그 에러 0
- **영역**: `05.Prefabs\`(UI), **`01.Scenes\MainScene.unity`**, `UI\`
