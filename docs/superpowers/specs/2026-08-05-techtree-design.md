# 테크트리 — AI가 배우는 세계

- 작성일: 2026-08-05
- 상위 문서: `2026-08-04-p2-depth-gating-design.md`
- 결정 주체: 사용자 브레인스토밍 (2026-08-05)

---

## 1. 목적

재료 게이팅 위에 **연구 게이팅**을 한 겹 얹는다. 제작·건축은 거의 전부 잠긴 채 시작하고, 세계를 만지고(첫 습득) 위험을 감수해(유물·부품) 아는 것을 늘려야 열린다. 서사 축은 **우주복 AI** — 플레이어가 주운 것을 AI가 분석하고, 재설계하고, 말을 건다.

Raft의 연구 테이블을 참조하되, 이 게임의 것으로 옮긴다: 연구 테이블이 아니라 **AI를 입력한 연구대**, 연구 재화가 아니라 **낫의 그림자에서 주운 유물**.

---

## 2. 해금 채널 둘

### 채널 1 — 현장 발견 (몸의 AI, 즉시)

재료를 **처음 주울 때** AI가 반응하며 관련 기본 레시피가 열린다.

- 버섯 목재 → "목재처럼 쓸 수 있겠어" → 기본 건축
- 돌 → "충분히 강하다" → 돌 도구
- 스크랩 → 화톳불·기본 제작

시작 시 열린 것은 최소한(화톳불 정도). 챕터 1 초반 동선이 그대로 자연 튜토리얼이 된다. AI 대사는 기존 자막(SubtitleLine)으로.

**AI 문체 (2026-08-05 최종)**: 로봇식 분석 보고체 — **"[성질 묘사] 분석... [용도 판정, '~것으로 보입니다' 관찰투]. 해당 물질을 사용한 제작법이 있습니다."** 아이템 이름을 되뇌지 않고 관찰된 성질을 묘사한다(분석기는 라벨을 모른다). 3문장 이내, 효율 최우선. 기준 예문(스크랩): *"외계 금속물체 분석... 에너지로 사용가능한 것으로 보입니다. 해당 물질을 사용한 제작법이 있습니다."* 감탄·의인화 감상 금지.

### 채널 2 — 연구대 (AI를 입력한 장치)

- **연구대** = 신규 건축물. AI를 연결하면 **스크랩을 에너지로 소모**해 추가 연산을 돌린다 (스크랩 = 에너지 저장 매체 픽션의 연장).
- 연구 = 소재 + 스크랩 투입 + **시간 소요** — 시간 제작(R9-C)의 스테이션 Job 큐를 그대로 재사용. 산출물이 아이템이 아니라 **해금**일 뿐이다.
- 진행 장비(산소 상향·액면 보행·잠항구 등)는 이 채널 뒤에 선다. 유물을 들고 낫의 영역에서 살아 돌아와, 거점에서 밝혀내는 왕복 리듬.

### 연구 소재

| 소재 | 출처 | 해금 |
|---|---|---|
| **유물** | 낫이 순찰 경로에 가끔 떨어뜨림 | **종별 고유 해금** (도감 수집) |
| **생물 부품** | 생물 처치 드롭 (공 등) | **종별 고유 해금** |

**드롭 안전장치**: 낫의 유물 드롭은 **미보유 종 우선**(pity) — 운 나쁜 중복 드롭이 진행을 막지 못하게 한다.

## 3. 분해 — 세 조각

연구대는 본질적으로 스테이션 제작의 세 번째 인스턴스다(손·제작대·화톳불에 이어). 산출물 타입만 다르다.

| # | 조각 | 내용 | 의존 |
|---|---|---|---|
| 37 | **해금 상태 코어** | 청사진 잠금/해금 단일 원장(Domain 순수 상태) + 세이브 지속 + 제작·건축 UI 게이팅(실루엣+조건 표시) + **채널 1 전체** | 없음 (독립) |
| 38 | **연구대 스테이션** | 신규 건축물 + "산출물=해금"인 스테이션 Job + 소재·스크랩 투입 UI(스테이션 제작 UI 문법 재사용) + AI 대사 | R9-C(Job 큐) + 37 |
| 39 | **연구 소재 공급** | 낫 순찰 유물 드롭(pity) + 생물 부품 드롭 테이블 | 없음 (Creatures 영역, 병렬 가능) |

## 4. 데이터

전부 ScriptableObject (사용자 원칙: 추후 인스펙터 수정 가능):
- 해금 매핑(무엇을 주우면/연구하면 무엇이 열리나), 연구 항목(소재 요구·스크랩 비용·소요 시간), AI 대사 텍스트.
- `RecipeSO`/`BuildCatalogSO`에는 "요구 청사진" 참조만 얹는다 — 기존 재료 게이팅과 독립인 이중 잠금.

## 5. 검증

**[자동]** 해금 원장 Domain 테스트(중복 해금·미지 키·세이브 왕복) / 채널 1 E2E(첫 습득→해금→제작 가능) / 연구대 E2E(소재+스크랩+시간→해금, 스크랩 부족·소재 부족 거부) / 드롭 E2E(pity 순서) / 잠금 상태 UI 표시 / 기존 E2E 전면 개정(동선 중 자연 해금이 성립하는가 — E2EChapter1이 최종 심판).

**[사람]** 해금 페이스가 답답하지 않은가, AI 대사가 과하지 않은가.

## 6. 순서

R9-C 병합 → **R10**: 목재(35, 클론 C) + 챕터 종막(36, 클론 A) + **테크트리 37(클론 B)** → **R11**: 38 + 39. (37·39는 R10과 영역이 분리되어 병렬 가능, 38만 R9-C·37 의존.)

## 7. 범위 밖

- 연구 트리 시각화 화면(노드 그래프 UI) — 잠금 표시와 연구대 목록으로 족하다. 수요가 생기면 별도.
- 유물의 서사 내용(각 유물이 무엇인가) — 챕터 2 서사와 함께.
