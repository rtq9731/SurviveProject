## 1. 확정된 방향

| # | 결정 | 근거 |
|---|---|---|
| R1 | **깊이 게이팅 탐사(A)를 뼈대로, 코어 복원(C)을 결말로** | 기획서 맵 설계가 이미 깊이 진행형이다(부유섬 400~600m → 평야 800~1200m → 절벽 1200~2000m). 생태계 문서의 "깊이가 곧 풍요"도 같은 축이다. 무엇보다 **깊을수록 어둡고, 어두울수록 저폴리 아트가 드러나지 않는다** |
| R2 | **구역 관문은 환경 장벽 + 장비로 잠근다** | 보스로 잠그면 고유 실루엣을 가진 보스 에셋이 필요한데 없다. 환경으로 막으면 아트 비용이 0이다 |
| R3 | **싱글로 만들되 코옵 구조는 열어둔다** | 저폴리 생존게임 성공 사례가 거의 전부 코옵이다(§3.2). 지금 붙이면 작업량이 배가 되지만, 나중에 못 붙이면 가장 큰 성공 경로가 닫힌다. 타협점은 **권위 소유 모델을 P2부터 코딩 규칙으로 적용**하는 것 |
| R4 | **생물은 분해자·생산자·소비자 3계층을 구역마다 배치** | 기획서 생물 분류를 그대로 쓴다. 구역 정체성이 생태 구성으로 드러난다 |
| R5 | **부유섬 하나로 얼리액세스 출시 후 확장** | 3구역 풀게임을 다 만들고 내면 출시 전까지 시장 반응을 전혀 모른다. 생존게임은 EA가 예외가 아니라 표준 경로다 |
| R6 | **아트 예산을 조명·포스트프로세싱에 전부 몰아넣는다** | Iron Gate(Valheim, 5인, 1,200만 장)의 방침과 같다 — "텍스처 품질과 폴리곤 수보다 구도와 조명이 중요하다" |

## 2. 레퍼런스 — 무엇을 훔칠 것인가

통째로 닮으려 하면 아트에서 진다. 게임마다 **하나씩만** 가져온다.

| 게임 | 훔칠 것 |
|---|---|
| **The Forest** | 동굴 설계 문법 — 좁은 통로/개활지 교대 리듬, 편도 낙하로 "돌아갈 길이 없다" 만들기 |
| **Muck** | 티어 명료성 — 자원 이름만 보고 몇 단계인지 안다. 헷갈리지 않는 진행 축 |
| **Deep Rock Galactic** | 어둠을 자원으로 — 시야를 "사서 쓴다". 랜턴 배터리를 소모품이 아니라 전술 자원으로 |
| **Dome Keeper** | 왕복 압박 리듬 — 배터리가 반 남았을 때 "더 갈까 돌아갈까" |
| **Core Keeper** | 구역 게이팅 구조 |
| **Valheim** | 포탈 네트워크 — 이미 포탈이 있다. 이동 수단으로 승격시키면 3구역 왕복이 성립한다 |
| **Subnautica** | "장비 없이는 못 가는 깊이" — 벽이 아니라 환경으로 막는다 |
| **The Planet Crafter** | 코어 복원 결말의 구현 — 수치가 오르면 세계가 물리적으로 변한다 |
| **Abiotic Factor** | 지하만으로 풀게임이 성립한다는 증명 — 넓은 자연 렌더링 부담을 아예 안 진다 |

**Muck의 구조는 가져오지 않는다.** 로그라이트는 런 단위 리셋이 전제라, 지속형 세계 10시간과 맞지 않는다. 가져올 것은 구조가 아니라 명료함이다.

**The Forest에서 그대로 가져오면 안 되는 것 하나**: 더 포레스트의 긴장은 "지상은 안전, 지하는 지옥"이라는 대비에서 나온다. **우리는 전부 지하라 그 대비축이 없다.** 대신 **밝은 곳 / 어두운 곳**으로 축을 다시 세운다. 불씨버섯 군락이 "지하판 지상"이고, 플레이어가 세우는 화톳불이 "직접 만드는 밝은 곳"이다. 이것이 건축의 존재 이유가 된다.

## 3. 근거 데이터

### 3.1 저폴리는 생존게임에서 불리하지 않다

| 게임 | 판매량 | 팀 규모 | 아트 |
|---|---|---|---|
| Valheim | 1,200만+ | 5명 | 의도적 저폴리 + 일부러 낮춘 텍스처 해상도 |
| Raft | 1,300만~1,800만 | 소규모(학생 프로젝트 출신) | 스타일라이즈드 저폴리 |
| Astroneer | 710만~780만 (약 $165M) | 소규모 | 저폴리 |
| Abiotic Factor | 140만 | 소규모 | 일부러 레트로 저폴리 |
| The Planet Crafter | 100만+ | 소규모 | 저폴리. **"인디치고도 그래픽이 별로"라는 평을 받으며 스팀 96% 압긍** |

생존게임 판매 상위권에 저폴리가 둘(Valheim, Raft) 있다. "저폴리는 생존게임에서 잘 없다"는 사실이 아니다.

**다만 위 게임들은 전부 저폴리를 *선택한* 게임이지, 아트가 없어서 저폴리가 된 게임이 아니다.** 팔레트가 통제되어 있고 모든 오브젝트가 같은 규칙으로 만들어져 있다.

### 3.2 우리의 실제 위험은 폴리곤 수가 아니라 "에셋 조합 티"

Poly Universal Pack 6484개를 Fantasy·City·Steampunk·Farm에서 골라 섞으면, 각각은 멀쩡한데 한 화면에 모이면 출처가 다 보인다. 이것이 아마추어처럼 보이는 진짜 원인이며, **P0가 존재하는 이유다.**

지하라는 무대가 이 문제에 유리하다. 야외 게임은 모든 오브젝트가 대낮에 다 보이지만, 우리는 랜턴 반경 밖을 아예 안 보여줄 수 있다.

### 3.3 생존게임은 스팀에서 성공률 1위 장르다

2025년 스팀 출시작 기준 1,000리뷰(≈ 매출 $150,000) 돌파율:

| 장르 | 돌파율 |
|---|---|
| **Open World Survival Craft** | **20.8%** (72개 중 15개) |
| 농장 시뮬 | 8.3% |
| 로그라이크 덱빌더 | 5.1% |
| 스팀 전체 평균 | 3.0% |
| 3D 플랫포머 | 0.05% |
| 퍼즐 | 0.34% |

과포화의 정의는 "공급이 많다"가 아니라 **"공급 대비 수요가 부족하다"** 이다. 생존게임은 공급도 많지만 수요가 훨씬 더 많다.

**정직하게 짚을 것**:
- 72개 중 57개는 실패했다. 20.8%는 상대적으로 좋은 확률이지 안전한 확률이 아니다
- 2024년 24.47% → 2025년 20.8%로 **하락 중**이다. Open World Survival Craft는 2025년 스팀 상위 10개 장르에서 밀려났다
- 성공 사례가 코옵에 몰려 있다 → R3이 사업 판단인 이유

### 3.4 공짜로 얻는 포지셔닝

2026년 스팀에서 심리·분위기 호러가 90일 위시리스트 평균 **572% 성장**(스팀 평균 4.6%)으로 최고 수요 신호를 냈다. 우리 게임은 이미 지하·어둠·랜턴 배터리·AI 흑막으로 구성되어 있으므로, 태그를 `Survival Craft` + `Atmospheric` + `Horror`로 잡으면 **성공률 1위 장르와 수요 급등 장르 양쪽에 동시에 걸린다.** 코드 없이 얻는 이점이다.

### 3.5 차별화 축

생존게임 5개 중 1개가 성공한다는 것은 장르 선택이 유리하다는 뜻이지 아무거나 만들어도 된다는 뜻이 아니다. **대부분의 생존게임에서 자원은 그냥 리스폰된다 — 관찰할 것이 없다.** 우리의 축은 생태계 문서 §4.2에 이미 적혀 있다:

- 배부른 생산자는 몸체가 부풀고 접합부가 빛난다 → 아무거나 잡지 말고 배부른 개체를 노린다
- 잔해를 오래 두면 분해자가 가져간다 → 전투 후 빨리 회수해야 한다
- 식물을 과하게 캐면 그 구역 생산자가 줄어든다 → 채집 구역을 돌려 쓴다
- 매크로늄 이끼가 짙은 곳에 맥이 있다 → 이끼를 단서로 자원지를 찾는다

**"생태계를 읽으면 이득을 본다"** — 스팀 페이지 첫 문장이자, 아트 없이 시스템만으로 만드는 차별화다.

## 4. 두 가지 발견

### 4.1 낮과 밤이 이미 설정에 있다

생태계 문서 등불버섯 항목:

> 빛은 일정하지 않고 매크로늄 공급에 따라 수 시간 주기로 밝아졌다 어두워지기를 반복한다 — **지하의 낮과 밤에 해당한다.**

낮/밤을 새로 발명할 필요가 없다. 그리고 **부유섬엔 등불버섯이 없으므로 챕터 1에 밤이 없는 것이 설정상 당연하다.** 밤은 평야에서 처음 온다. 새 시스템의 도입 시점이 서사와 일치한다.

밤은 조명 연출이 아니라 **위협 주기이자 거점의 존재 이유**로 쓴다. 밤에는 세계 전체가 랜턴 반경으로 줄어든다.

### 4.2 생물 에셋이 0개인데 문제가 되지 않는다

Poly Universal Pack 6484개에 동물·크리처 프리팹이 없다. 현재 생물은 자체 생성 FBX 4개뿐이다(`ball`, `eye`, `wing`, `fruitcrab`).

**그러나 이 게임은 기계 생태계다. 생물이 유기체일 필요가 없다.** 기계 생물은 코어 + 이동부 + 부속의 **모듈 조립**으로 만들 수 있고, 조립 규칙 자체가 아트 디렉션이 된다.

계층을 실루엣으로 읽히게 만든다:

| 계층 | 조립 규칙 | 플레이어가 읽는 것 |
|---|---|---|
| 분해자 (1차) | 코어 1 + 단순 이동부, 부속 없음 | 작고 둥글다 = 무해 |
| 생산자 (2차) | 코어 + 이동부 + 저장부(먹으면 부풀고 빛남) | 배부른 개체를 노린다 |
| 소비자 (3차) | 코어 + 다관절 이동부 + 공격부(날붙이·집게) | 뾰족하다 = 도망친다 |

실루엣만으로 위험도가 읽혀야 한다. **저폴리 + 어둠 조합에서 이것은 선택이 아니라 필수 조건이다.**

### 4.3 부유섬의 소비자 — 설정 충돌과 해소

R4("3계층을 구역마다")와 기존 설정이 충돌한다. 기획서와 생태계 문서 §4.4는 **부유섬 서식 생물을 소형 분해자·생산자로 한정**한다. 매크로늄이 옅어 생태계가 빈약하다는 설정이고, 이것이 챕터 1에 랜턴이 필요한 이유이기도 하다. 여기에 소비자를 그냥 얹으면 설정이 깨진다.

**해소**: P2가 부유섬을 수직으로 확장한다(얕은 층 / 깊은 층). 소비자는 **깊은 층에만** 둔다.

- 부유섬 지표는 여전히 빈약하다 — 설정이 유지된다
- 깊이 내려가면 소비자가 있다 — EA 빌드에 위협이 생긴다
- "깊이가 곧 풍요"라는 생태계 원칙이 부유섬 안에서 먼저 증명된다
- 플레이어는 "더 깊이 가면 더 위험하다"를 챕터 1에서 학습하고 평야에 간다

즉 **부유섬의 소비자는 상주종이 아니라 깊은 층의 거주자**다. 종 수는 1종으로 족하다.

## 5. 얼리액세스 범위

### 5.1 EA 빌드에 들어가는 것

무대는 **부유섬 하나**. 다음이 전부 성립해야 한다.

- 완결된 코어 루프 — 탐사 → 채집 → 제작 → 장비 → 더 깊이
- 깊이 게이팅이 부유섬 **안에서** 작동 (얕은 층 / 깊은 층)
- 생물 3계층이 부유섬 규모로 존재 (소비자는 깊은 층 1종 — §4.3)
- 건축·거점이 "밝은 곳을 직접 만든다"는 의미를 가짐
- 세이브 견고성, 튜토리얼, 스팀 페이지·트레일러

**분량 목표 3~5시간.** 현재 챕터 1은 자동 완주 149초, 실플레이 30~60분 수준이므로 **부유섬을 5~8배로 키워야 한다.** 기획서상 부유섬은 400~600m 구간이므로 공간은 있다. 지금 쓰지 않고 있을 뿐이다.

### 5.2 EA에 밤이 없는 문제 — 업데이트 설계로 전환

부유섬엔 등불버섯이 없어 EA 빌드엔 밤이 없다. 이를 결함이 아니라 **업데이트 순서**로 쓴다.

| 시점 | 무대 | 그때 처음 들어오는 것 |
|---|---|---|
| **EA 출시** | 부유섬 | 랜턴 배터리가 유일한 시계. "돌아갈 수 있을 때 돌아가라" 압박 |
| EA 업데이트 1 | 평야 | **밤이 처음 온다.** 등불버섯·숲·거점 방어 |
| EA 업데이트 2 | 절벽 | 최심부·MARSO |
| 1.0 | 전 구역 | 코어 복원 결말 |

부유섬은 "밤이 없어 밋밋한 곳"이 아니라 **"아직 밤을 모르는 곳"** 이다. EA 업데이트마다 새 시스템이 하나씩 들어오는 구조를 설정이 이미 정해 두었다.

## 6. 단계

각 단계는 **독립적인 스펙 → 플랜 → 구현 사이클**을 갖는다. 전체를 한 스펙에 담지 않는다.

| # | 단계 | 만들 것 | EA 필수 |
|---|---|---|---|
| **P0** | 아트 방향 확립 | 구역별 팔레트·포그·조명 규칙, 머티리얼 통일 레이어, 실루엣 규칙 | ✅ |
| **P1** | 챕터 1 마감 | 모듈 건축 완결, 화톳불=밝은 곳 승격, 진행 중 작업 정리 | ✅ |
| **P2** | 깊이 게이팅 코어 | 환경 위협(어둠 강도·유독·수심), 장비 티어 + 보호 스탯, 자원 티어, 왕복 압박 리듬, 부유섬 수직 확장 | ✅ |
| **P3** | 생물 3계층 | 기계 생물 모듈 조립 시스템, 소비자 AI, 구역별 종 배치 | ✅ (부유섬 분량) |
| **P-EA** | 출시 준비 | 스팀 페이지, 트레일러, 데모, 세이브 견고성, 튜토리얼 | ✅ |
| P4 | 평야 + 밤 | 새 맵, 숲, 등불버섯 주기(낮/밤), 거점 방어, 포탈 네트워크 | 업데이트 1 |
| P5 | 절벽 | 늪지, 최심부, MARSO 대면 | 업데이트 2 |
| P6 | 코어 복원 | 세계 상태 변화 시스템 | 1.0 |
| P7 | 1.0 마감 | 사운드, 설정, 로컬라이즈, 최적화, 스팀 연동 | 1.0 |
| (상시) | 코옵 대비 | 권위 소유 모델을 P2부터 코딩 규칙으로 | — |

### 순서의 근거

- **P0가 먼저인 이유**: 가장 싸고, 나중에 하면 가장 비싸다. 이후 모든 에셋이 이 규칙을 통과해야 하며, EA 스크린샷과 트레일러가 전부 여기서 나온다
- **P1이 P2보다 먼저인 이유**: 모듈 건축이 이미 반쯤 만들어져 있다. 열어두면 계속 샌다
- **P2가 P3보다 먼저인 이유**: 생물은 환경 위협 위에 얹힌다. 환경이 없으면 생물이 유일한 위협이 되어 아트 부담이 정면으로 드러난다
- **P4가 EA 이후인 이유**: 밤·숲·등불버섯은 평야의 콘텐츠다. 부유섬 EA에 넣을 수 없고, 넣으면 설정이 깨진다
