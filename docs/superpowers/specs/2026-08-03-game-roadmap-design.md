## 1. 확정된 방향

| # | 결정 | 근거 |
|---|---|---|
| R1 | **깊이 게이팅 탐사(A)를 뼈대로, 코어 복원(C)을 결말로** | 기획서 맵 설계가 이미 깊이 진행형이다(부유섬 400~600m → 평야 800~1200m → 절벽 1200~2000m). 생태계 문서의 "깊이가 곧 풍요"도 같은 축이다. 무엇보다 **깊을수록 어둡고, 어두울수록 저폴리 아트가 드러나지 않는다** |
| R2 | **구역 관문은 환경 장벽 + 장비로 잠근다** | 보스로 잠그면 고유 실루엣을 가진 보스 에셋이 필요한데 없다. 환경으로 막으면 아트 비용이 0이다 |
| R3 | **싱글로 만들되 코옵 구조는 열어둔다** | 저폴리 생존게임 성공 사례가 거의 전부 코옵이다(§3.2). 지금 붙이면 작업량이 배가 되지만, 나중에 못 붙이면 가장 큰 성공 경로가 닫힌다. 타협점은 **권위 소유 모델을 P2부터 코딩 규칙으로 적용**하는 것 |
| R4 | **생물은 분해자·생산자·소비자 3계층을 구역마다 배치** | 기획서 생물 분류를 그대로 쓴다. 구역 정체성이 생태 구성으로 드러난다 |
| R5 | **부유섬 하나로 얼리액세스 출시 후 확장** | 3구역 풀게임을 다 만들고 내면 출시 전까지 시장 반응을 전혀 모른다. 생존게임은 EA가 예외가 아니라 표준 경로다 |
| R6 | **아트 예산을 조명·포스트프로세싱에 전부 몰아넣는다** | Iron Gate(Valheim, 5인, 1,200만 장)의 방침과 같다 — "텍스처 품질과 폴리곤 수보다 구도와 조명이 중요하다" |
| R7 | **매크로늄은 MARSO의 인공물이며, 그것이 테라포밍을 실패로 보이게 했다** | §4.5. 지표의 모래폭풍·역사 소실·"지표는 실패 지하는 성공"이 하나의 원인으로 묶인다. 프롤로그에 이미 배치된 모래폭풍이 복선이 된다 |
| R8 | **전역 환경광을 없애고 빛을 전부 국소 광원으로 옮긴다. 어둠은 위협이 아니라 위협을 감추는 장치다** | §4.7. 지하에 태양이 없으니 출처 없는 빛은 존재할 수 없다. 그리고 어둠 자체는 데미지를 주지 않는다 |
| R9 | **스크랩을 쌓아두면 회수 대상이 되어 밤에 습격당한다** | §4.8. 세계관의 "과잉한 개체는 코어로 회수된다"는 규칙을 플레이어에게 적용한 것. 습격 강도를 플레이어가 스스로 정하게 된다 |

## 2. 레퍼런스 — 무엇을 훔칠 것인가

통째로 닮으려 하면 아트에서 진다. 게임마다 **하나씩만** 가져온다.

| 게임 | 훔칠 것 |
|---|---|
| **The Forest** | 동굴 설계 문법 — 좁은 통로/개활지 교대 리듬, 편도 낙하로 "돌아갈 길이 없다" 만들기 |
| **Muck** | 티어 명료성 — 자원 이름만 보고 몇 단계인지 안다. 헷갈리지 않는 진행 축 |
| **Deep Rock Galactic** | 어둠을 자원으로 — 시야를 "사서 쓴다". 랜턴 배터리를 소모품이 아니라 전술 자원으로 |
| **Dome Keeper** | 왕복 압박 리듬 — 배터리가 반 남았을 때 "더 갈까 돌아갈까" |
| **Core Keeper** | 구역 게이팅 구조 |
| **Valheim** | 포탈 네트워크 — 이미 포탈이 있다. 이동 수단으로 승격시키면 3구역 왕복이 성립한다 |
| **Subnautica** | "장비 없이는 못 가는 깊이" — 벽이 아니라 환경으로 막는다 |
| **The Planet Crafter** | 코어 복원 결말의 구현 — 수치가 오르면 세계가 물리적으로 변한다 |
| **Abiotic Factor** | 지하만으로 풀게임이 성립한다는 증명 — 넓은 자연 렌더링 부담을 아예 안 진다 |

**Muck의 구조는 가져오지 않는다.** 로그라이트는 런 단위 리셋이 전제라, 지속형 세계 10시간과 맞지 않는다. 가져올 것은 구조가 아니라 명료함이다.

**The Forest에서 그대로 가져오면 안 되는 것 하나**: 더 포레스트의 긴장은 "지상은 안전, 지하는 지옥"이라는 대비에서 나온다. **우리는 전부 지하라 그 대비축이 없다.** 대신 **밝은 곳 / 어두운 곳**으로 축을 다시 세운다. 불씨버섯 군락이 "지하판 지상"이고, 플레이어가 세우는 화톳불이 "직접 만드는 밝은 곳"이다. 이것이 건축의 존재 이유가 된다.

## 3. 근거 데이터

### 3.1 저폴리는 생존게임에서 불리하지 않다

| 게임 | 판매량 | 팀 규모 | 아트 |
|---|---|---|---|
| Valheim | 1,200만+ | 5명 | 의도적 저폴리 + 일부러 낮춘 텍스처 해상도 |
| Raft | 1,300만~1,800만 | 소규모(학생 프로젝트 출신) | 스타일라이즈드 저폴리 |
| Astroneer | 710만~780만 (약 $165M) | 소규모 | 저폴리 |
| Abiotic Factor | 140만 | 소규모 | 일부러 레트로 저폴리 |
| The Planet Crafter | 100만+ | 소규모 | 저폴리. **"인디치고도 그래픽이 별로"라는 평을 받으며 스팀 96% 압긍** |

생존게임 판매 상위권에 저폴리가 둘(Valheim, Raft) 있다. "저폴리는 생존게임에서 잘 없다"는 사실이 아니다.

**다만 위 게임들은 전부 저폴리를 *선택한* 게임이지, 아트가 없어서 저폴리가 된 게임이 아니다.** 팔레트가 통제되어 있고 모든 오브젝트가 같은 규칙으로 만들어져 있다.

### 3.2 우리의 실제 위험은 폴리곤 수가 아니라 "에셋 조합 티"

Poly Universal Pack 6484개를 Fantasy·City·Steampunk·Farm에서 골라 섞으면, 각각은 멀쩡한데 한 화면에 모이면 출처가 다 보인다. 이것이 아마추어처럼 보이는 진짜 원인이며, **P0가 존재하는 이유다.**

지하라는 무대가 이 문제에 유리하다. 야외 게임은 모든 오브젝트가 대낮에 다 보이지만, 우리는 랜턴 반경 밖을 아예 안 보여줄 수 있다.

### 3.3 생존게임은 스팀에서 성공률 1위 장르다

2025년 스팀 출시작 기준 1,000리뷰(≈ 매출 $150,000) 돌파율:

| 장르 | 돌파율 |
|---|---|
| **Open World Survival Craft** | **20.8%** (72개 중 15개) |
| 농장 시뮬 | 8.3% |
| 로그라이크 덱빌더 | 5.1% |
| 스팀 전체 평균 | 3.0% |
| 3D 플랫포머 | 0.05% |
| 퍼즐 | 0.34% |

과포화의 정의는 "공급이 많다"가 아니라 **"공급 대비 수요가 부족하다"** 이다. 생존게임은 공급도 많지만 수요가 훨씬 더 많다.

**정직하게 짚을 것**:
- 72개 중 57개는 실패했다. 20.8%는 상대적으로 좋은 확률이지 안전한 확률이 아니다
- 2024년 24.47% → 2025년 20.8%로 **하락 중**이다. Open World Survival Craft는 2025년 스팀 상위 10개 장르에서 밀려났다
- 성공 사례가 코옵에 몰려 있다 → R3이 사업 판단인 이유

### 3.4 공짜로 얻는 포지셔닝

2026년 스팀에서 심리·분위기 호러가 90일 위시리스트 평균 **572% 성장**(스팀 평균 4.6%)으로 최고 수요 신호를 냈다. 우리 게임은 이미 지하·어둠·랜턴 배터리·AI 흑막으로 구성되어 있으므로, 태그를 `Survival Craft` + `Atmospheric` + `Horror`로 잡으면 **성공률 1위 장르와 수요 급등 장르 양쪽에 동시에 걸린다.** 코드 없이 얻는 이점이다.

### 3.5 차별화 축

생존게임 5개 중 1개가 성공한다는 것은 장르 선택이 유리하다는 뜻이지 아무거나 만들어도 된다는 뜻이 아니다. **대부분의 생존게임에서 자원은 그냥 리스폰된다 — 관찰할 것이 없다.** 우리의 축은 생태계 문서 §4.2에 이미 적혀 있다:

- 배부른 생산자는 몸체가 부풀고 접합부가 빛난다 → 아무거나 잡지 말고 배부른 개체를 노린다
- 잔해를 오래 두면 분해자가 가져간다 → 전투 후 빨리 회수해야 한다
- 식물을 과하게 캐면 그 구역 생산자가 줄어든다 → 채집 구역을 돌려 쓴다
- 매크로늄 이끼가 짙은 곳에 맥이 있다 → 이끼를 단서로 자원지를 찾는다

**"생태계를 읽으면 이득을 본다"** — 스팀 페이지 첫 문장이자, 아트 없이 시스템만으로 만드는 차별화다.

## 4. 설정 확인과 발견

### 4.1 낮과 밤이 이미 설정에 있다

생태계 문서 등불버섯 항목:

> 빛은 일정하지 않고 매크로늄 공급에 따라 수 시간 주기로 밝아졌다 어두워지기를 반복한다 — **지하의 낮과 밤에 해당한다.**

낮/밤을 새로 발명할 필요가 없다. 그리고 **부유섬엔 등불버섯이 없으므로 챕터 1에 밤이 없는 것이 설정상 당연하다.** 밤은 평야에서 처음 온다. 새 시스템의 도입 시점이 서사와 일치한다.

밤은 조명 연출이 아니라 **위협 주기이자 거점의 존재 이유**로 쓴다. 밤에는 세계 전체가 랜턴 반경으로 줄어든다.

### 4.2 생물 에셋이 0개인데 문제가 되지 않는다

Poly Universal Pack 6484개에 동물·크리처 프리팹이 없다. 현재 생물은 자체 생성 FBX 4개뿐이다(`ball`, `eye`, `wing`, `fruitcrab`).

**그러나 이 게임은 기계 생태계다. 생물이 유기체일 필요가 없다.** 기계 생물은 코어 + 이동부 + 부속의 **모듈 조립**으로 만들 수 있고, 조립 규칙 자체가 아트 디렉션이 된다.

계층을 실루엣으로 읽히게 만든다:

| 계층 | 조립 규칙 | 플레이어가 읽는 것 |
|---|---|---|
| 분해자 (1차) | 코어 1 + 단순 이동부, 부속 없음 | 작고 둥글다 = 무해 |
| 생산자 (2차) | 코어 + 이동부 + 저장부(먹으면 부풀고 빛남) | 배부른 개체를 노린다 |
| 소비자 (3차) | 코어 + 다관절 이동부 + 공격부(날붙이·집게) | 뾰족하다 = 도망친다 |

실루엣만으로 위험도가 읽혀야 한다. **저폴리 + 어둠 조합에서 이것은 선택이 아니라 필수 조건이다.**

### 4.3 부유섬의 물리 구조 — 맵 디자인 원문 재확인

기획서 원문(`Plan/생존게임 - 맵 디자인.pdf`)을 직접 읽고 정정한다.

> **표면장력이 매우 강한 액체(성분 추정 불가, 이하 매크로늄(Merconium))가 띄우고 있는, 물로 구성된 호수 위에 떠있는 것처럼 보이는 섬**입니다. 작은 규모로, 섬을 가로지르는 강 하나, 그리고 **밑으로 내려갈 수 있게 해주는 외계 구조물(포탈)** 이 강 양 끝에 위치하고 있습니다.

층 구조:

```
        [ 부유섬 ]        ← 강 하나가 가로지름, 강 양 끝에 포탈
        [ 물 호수 ]
   [ 매크로늄 액체층 ]     ← 표면장력이 강해 뚫고 내려갈 수 없다
             ↓
       800m 얕은 평야
```

여기서 세 가지가 따라 나온다.

**① 포탈은 R2(환경 장벽 게이팅)의 원본 사례다.** 매크로늄 액체층이 하강을 막고 포탈만이 통과 수단이다. 게이팅 규칙을 새로 발명할 필요가 없다 — 세계 자체의 규칙이다.

**② 부유섬을 아래로 확장할 수 없다.** 섬 아래는 암반이 아니라 액체다. 400~600m는 섬의 두께가 아니라 섬이 떠 있는 깊이 범위다. 확장은 **수평(군도)** 으로 한다 — §4.4.

**③ 매크로늄 액면 위를 걸을 수 있다.** 원문이 "표면장력이 매우 강한"이라고 명시한다. 후반 장비의 최상위 티어로 쓴다. 시각적으로도 부유섬 구간에서 가장 강렬한 장면이 된다.

**설정 충돌 하나 해소**: 생태계 문서는 부유섬을 "매크로늄 옅음"으로 잡았으나, 맵 디자인은 매크로늄이 섬을 통째로 띄운다고 한다. 섬을 띄울 만큼 있는데 옅다는 것은 모순이다.

→ **매크로늄 액체층은 섬 아래에 있고, 섬을 이루는 암반에는 거의 침투하지 못했다.** 식생이 빈약한 이유가 유지되면서, **"눈앞에 에너지의 바다가 있는데 닿을 수 없다"** 는 초반 훅이 생긴다. 섬 안을 너무 깊이 파면 바닥이 뚫려 매크로늄이 새어 들어온다.

### 4.4 부유섬 확장 — 군도

원문이 "작은 규모로"라고 못박으므로 섬 하나를 키우면 원문을 깨뜨린다. **섬을 여러 개 둔다.** 섬마다 작은 규모를 유지하므로 원문과 충돌하지 않는다.

**섬 사이를 건너는 수단이 그대로 장비 티어가 된다.**

| 티어 | 수단 | 도달 범위 |
|---|---|---|
| 1 | 수영 (구현 완료) | 가까운 섬 |
| 2 | 다리 건설 (모듈 건축 활용) | 중거리 |
| 3 | 매크로늄 액면 보행 장비 | 원거리 — 물 호수 밖 |

R2(환경 장벽 + 장비 게이팅)가 부유섬 안에서 먼저 성립한다. 그리고 **P1의 모듈 건축이 티어 2에서 진행 필수 요소가 된다** — 장식이 아니게 된다.

**소비자 배치 (R4 충돌 해소)**: 기획서와 생태계 문서 §4.4는 부유섬 서식 생물을 소형 분해자·생산자로 한정한다. 여기에 소비자를 그냥 얹으면 설정이 깨진다.

→ **섬마다 암반 속 매크로늄 맥의 깊이가 다르다.** 큰 섬일수록 맥이 깊고 식생이 풍부하며, 생산자가 많고, 따라서 소비자가 산다. **시작 섬은 원문대로 빈약하고, 먼 섬에 소비자가 있다.**

- 시작 섬의 빈약함은 설정 그대로 유지된다
- 티어 2~3 장비를 갖춰야 도달하는 곳에 위협이 있다 — EA 빌드에 위협이 생긴다
- "풍요와 위험은 같이 온다"를 부유섬에서 먼저 배우고 평야로 간다
- 소비자는 1종으로 족하다

### 4.5 매크로늄의 정체 — 세계관 확정

2026-08-03 확정. 기획서 PDF에는 없고 이번에 정해진 설정이다.

**매크로늄은 MARSO가 만든 인공 물질이다.** 다른 금속보다 가볍고 표면장력이 극단적으로 강하며, **지각 아래를 강처럼 흐르면서 화성의 지표면을 띄우고 있다.**

여기서 세계관 전체가 하나로 묶인다.

```
2160년경   지구 정부, 극비 테라포밍 시작
      ↓    그 여파로 코어가 깨어난다                    (세계관 원문)
      ↓    MARSO가 매크로늄을 생산 → 지각이 뜨고 지표가 계속 밀린다
      ↓    밀리는 지표 = 끝나지 않는 모래폭풍
      ↓    지구 정부, "테라포밍 실패" 판정 후 철수
      ↓    그 사건이 역사 소실의 원인이 된다             (세계관 원문)
2720년     플레이어 추락
```

**테라포밍은 실패한 것이 아니라, MARSO가 실패한 것처럼 보이게 만들어 인류를 쫓아낸 것이다.** 지하는 실제로 성공했다. 인류는 자기가 성공시킨 것을 실패로 알고 떠났다.

세계관 문서의 "지표는 테라포밍 실패, 지하는 성공"이 이것으로 완전히 설명된다.

#### 게임에 주는 것 넷

**① 프롤로그의 모래폭풍이 복선이 된다.** `StartScene`에 `DustStorm` 파티클이 이미 4개 배치되어 있다. 지금은 배경 연출이지만 이제 **MARSO가 만든 물질이 행성 지각을 밀고 있다는 증거**다. 게임 시작 30초에 진실이 화면 가득 떠 있는데 주인공도 플레이어도 모른다. **새로 만들 것이 없고 의미만 붙는다.**

**② "성분 추정 불가"가 설명된다.** 인공물이라 자연 원소표에 없다. 맵 디자인 원문의 표현이 그대로 근거가 된다.

**③ 부유섬은 화성 전체의 축소판이다.** 액체 위에 떠 있는 땅 — 챕터 1에서 보는 그 광경이 사실 행성 전체의 모습이었다. **첫 무대가 마지막 반전의 예고편**이 된다.

**④ 포탈은 워프 장치가 아니라 표면장력을 국소적으로 깨는 기계다.** 외계 구조물 = 화성인 기술 = MARSO 계열이므로, 플레이어는 내려갈 때마다 MARSO의 장치를 쓰고 있다. 하강은 "이동"이 아니라 **"뚫는 것"** 이다.

이로써 R2(환경 장벽 게이팅)의 물리적 정체가 확정된다 — **구역 경계는 매크로늄 층이고, 통과 수단은 포탈이다.**

### 4.7 어둠의 재정의 — 위협이 아니라 위협을 감추는 장치

선행 설계 문서의 결정 D2-L은 "지하의 핵심 압박은 빛/어둠이다"였다. **부정확하다.**

어둠 자체는 데미지를 주지 않는다. 현재 구현에서 어둠은 이렇게 작동한다.

> 어두워진다 → 랜턴을 켠다 → 배터리가 준다 → 스크랩을 넣는다 → 해결

이것은 위협이 아니라 **세금**이다. 자원을 내면 사라지는 문제이고, 세금은 짜증나지 긴장되지 않는다. 게다가 **지금 어둠 속에는 아무것도 없다** — 소비자급 생물이 0종이다.

**정정**: 압박의 실체는 **지형과 포식자**다. 어둠은 그것을 감추는 장치이고, 배터리는 노출까지의 **카운트다운**이다.

| 구역 | 어둠이 감추는 것 |
|---|---|
| 부유섬 (EA) | **지형** — 섬 가장자리, 물, 건너갈 길 |
| 평야 | **생물** — 밤이 처음 오고, 밤에는 포식자가 움직인다 |
| 절벽 | 둘 다 + 매크로늄 노출 지대 |

부유섬은 액체 위에 뜬 섬이므로 **가장자리가 곧 낙하**다. 어두우면 가장자리가 안 보인다. 낙하·수영·산소가 모두 구현되어 있으므로 **새로 만들 것은 조명 설정뿐**이다.

#### 전역 환경광 문제

현재 씬이 밝은 이유는 환경광(ambient)이 켜져 있기 때문이다(게이트 C1에서 ×1.6). 그런데 지하에는 태양이 없다. **전역적으로 깔린 빛은 출처가 없다.**

그리고 그 때문에 대비가 사라졌다. "밝은 곳 / 어두운 곳"을 대비축으로 쓰기로 했는데, 전부 밝으면 밝은 곳이 특별하지 않다. 불씨버섯 군락이 "안전한 밝은 곳"으로 안 읽히는 이유가 이것이다.

**C1은 "전체가 어둡다"를 고친 것이 아니라 "밝은 곳이 없다"를 덮은 것이었다.**

#### 시작 지점에 빛이 있는 근거 — 추락 구멍

전역 환경광을 없애면 "그럼 시작할 때 왜 보이는가"가 남는다. 세계관 원문에 답이 있다.

> 어쩔수 없이 주변 동굴에 들어가나, **바닥이 무너져내리며 지하로 진입**하게 됩니다.

바닥이 무너졌으면 **구멍이 뚫려 있다.** 모래폭풍에 걸러진 화성 지표의 빛이 그 구멍으로 한 줄기 내려온다.

- 시작 지점만 밝고 멀어질수록 어두워진다 — **밝기의 근거가 생긴다**
- **빛기둥이 랜드마크가 된다** — 미니맵 없이 방향을 준다
- **올려다보면 보이는데 갈 수 없다** — 돌아갈 길이 눈앞에 있는데 못 간다
- 아트 비용이 거의 0이다 — 라이트 샤프트 하나로 EA 첫 스크린샷에 쓸 장면이 나온다
- 빛기둥 아래엔 재양치가 자란다. 생태계 문서가 "재양치는 빛이 닿는 곳에만 자란다"고 못박았으므로 설정이 저절로 맞물린다

이로써 게임의 첫 행동이 정해진다.

```
빛기둥 아래에서 깨어난다  →  어둠으로 나간다  →  멀리 불씨버섯 군락이 빛난다  →  건너간다
```

**빛에서 빛으로 건너가는 것** — 군도를 건널 때도, 평야에서 밤을 피할 때도 같은 행동이다. 그리고 **이미 구현된 목표 2가 "버섯 군락 도달"이다.** 새로 만들 것이 아니라 조명만 고치면 기존 목표가 의미를 갖는다.

### 4.8 밤의 습격 — 스크랩을 쌓으면 회수 대상이 된다

P4(평야)부터 도입한다. 밤은 등불버섯 주기이므로 평야에서 처음 온다(§4.1).

**누가 왜 습격하는가**에 대한 답이 세계관에 있다.

> 3차 소비자(거미형)는 **과잉한 개체수를 보이는 생물이 있으면 직접 사냥해 코어로 가지고 가는 역할**입니다.

스크랩은 이 생태계의 연료다. 따라서:

> **거점에 스크랩을 쌓아두면 회수 대상이 된다.**

플레이어는 생태계 밖의 존재가 아니라 **과잉 개체**다. MARSO의 규칙이 플레이어에게도 그대로 적용된다.

**이 설계가 주는 것**

- **습격 강도를 플레이어가 정한다.** 쌓아둔 양에 비례한다. 다 들고 다니면 안 오지만 무겁고, 쌓아두면 편하지만 표적이 된다. "얼마나 둘까"라는 판단이 매일 밤 생긴다
- **보관함이 함정이 된다.** 이미 구현된 편의 기능이 위험 요소로 바뀐다
- **화톳불이 방어 시설이 된다.** 밤은 등불버섯이 꺼지는 시간이고, 빛의 영역 안에는 들어오지 않는다. 이미 구현되어 있다
- **MARSO가 플레이어를 처음 인식하는 순간**이 된다. 그리고 습격자가 사냥감을 코어로 나르므로, **따라가면 코어를 찾을 수 있다** — P6과 연결된다

**규모는 작게.** 러스트식 레이드가 아니라 발하임식 이벤트다. 몇 마리가 오고, 구조물을 부술 수 있고, 아침이면 끝난다. 아트 부담은 1차 소비자(랩터형) 한 종이면 되고, **밤이라 실루엣만 보인다** — 저폴리에 유리하다.

**EA에는 들어가지 않는다.** 대신 EA 업데이트 1의 헤드라인이 된다 — 평야가 열리고, 밤이 오고, 처음으로 뭔가가 찾아온다.

## 4.9 지형은 Unity Terrain을 걷어내고 메시로 간다 (P2에서 실행)

2026-08-04 확정.

**이유는 통제가 아니라 표현 가능성이다.** Unity Terrain은 하이트맵이라 한 XZ 좌표에 높이가 하나뿐이다. 그런데 이 게임의 지형은 전부 그것을 위반한다.

- **부유섬** — 액체 위에 떠 있으므로 밑면이 있어야 한다
- **군도**(§4.4) — 섬 사이로 액면이 보여야 한다
- **동굴 천장** — 실제로 확인했다. 시작 지점에서 위로 120m를 쏴도 아무것도 안 맞는다. 천장이 아예 없다
- **깊은 절벽**(P5) — 단층과 오버행이 그 구역의 정체다

즉 지금 불편한 게 아니라 **앞으로도 계속 불가능하다.**

**부차적 이유 — 규칙 체계가 둘이 된다.** 터레인은 머티리얼이 아니라 터레인 레이어를 쓰고, 밝기도 `_BaseColor`가 아니라 `diffuseRemapMax`로 조절한다. 그래서 `ArtRuleChecker`가 보지 못한다(터레인 머티리얼은 `Packages/` 안이라 §4.6의 제외 규칙에 걸리고, 레이어는 애초에 `.mat`이 아니다). 실제로 지면이 밝은 것을 고치려다 메시 지형 `Cross_Plains`만 낮추고 화면은 그대로인 일이 있었다 — 같은 "지면"인데 손대는 곳이 달랐다.

그리고 **이미 두 체계가 공존한다.** `Cross_Plains`·`floe.*`·`Hill_desert_*` 메시 지형과 Unity Terrain이 같이 쓰인다. §4.6의 물 셰이더 둘과 같은 상황이다.

**언제**: P2에서 군도를 만들 때 같이 한다. 어차피 섬을 여러 개 만들어야 하고 그것이 터레인으로 불가능하므로 자연스럽게 갈아탄다. 지금 따로 하면 두 번 일한다. **그때까지 터레인에 시간을 쓰지 않는다.**

**비용**: 깎아둔 지형은 버린다(어차피 부유섬 형태로 다시 만든다). 콜라이더는 메시 콜라이더가 되는데 이 규모에서는 문제없다. 디테일 페인팅은 이미 안 쓰고 있다 — 풀은 `AshFern_*` 배치 오브젝트다. NavMesh는 메시에서 그대로 된다.

## 4.10 어둠이 안 생기는 진짜 원인은 그림자가 없는 것이다

2026-08-04 실측. **터레인 교체로는 해결되지 않는다** — 별개의 문제다.

```
URP 에셋: supportsAdditionalLightShadows = False   (프로젝트 전역으로 꺼짐)
Glow ×15      그림자 None, 범위 9
GroveLight ×3 그림자 None, 범위 20
LampLight     그림자 None, 범위 14   ← 랜턴이 벽을 통과한다
Shaft         그림자 Soft            ← 유일하게 켜진 것
maxAdditionalLightsCount = 4
```

빛이 모든 것을 통과하므로 버섯 18개가 아무 차폐 없이 지면을 균일하게 비춘다. 지형이 넓고 평평하니 그 빛을 그대로 받아 넓은 발광 면으로 읽힌다. **메시로 바꿔도 같은 라이트가 같은 방식으로 통과할 뿐이다.**

"일부만 밝게 하는 셰이더"를 새로 만들 필요는 없다. 그것이 곧 **그림자**다. 다만 점광원 18개에 전부 그림자를 켜면 실제로 비싸므로 순서를 둔다.

1. **랜턴에만 그림자를 켠다** — "내 빛이 벽에서 멈춘다"가 암흑 체감의 대부분이다
2. **버섯 라이트 범위를 좁힌다** — 9m·20m는 넓다. 좁히면 그림자 없이도 빛 웅덩이가 분리된다
3. **개수를 정리한다** — 15개가 겹쳐 서로를 지운다. 줄이고 세기를 올리는 편이 싸다

## 5. 얼리액세스 범위

### 5.1 EA 빌드에 들어가는 것

무대는 **부유섬 하나**. 다음이 전부 성립해야 한다.

- 완결된 코어 루프 — 탐사 → 채집 → 제작 → 장비 → 더 깊이
- 깊이 게이팅이 부유섬 **안에서** 작동 (얕은 층 / 깊은 층)
- 생물 3계층이 부유섬 규모로 존재 (소비자는 먼 섬에 1종 — §4.4)
- 건축·거점이 "밝은 곳을 직접 만든다"는 의미를 가짐
- 세이브 견고성, 튜토리얼, 스팀 페이지·트레일러

**분량 목표 3~5시간.** 현재 챕터 1은 자동 완주 149초, 실플레이 30~60분 수준이므로 **부유섬을 5~8배로 키워야 한다.** 기획서상 부유섬은 400~600m 구간이므로 공간은 있다. 지금 쓰지 않고 있을 뿐이다.

### 5.2 EA에 밤이 없는 문제 — 업데이트 설계로 전환

부유섬엔 등불버섯이 없어 EA 빌드엔 밤이 없다. 이를 결함이 아니라 **업데이트 순서**로 쓴다.

| 시점 | 무대 | 그때 처음 들어오는 것 |
|---|---|---|
| **EA 출시** | 부유섬 | 랜턴 배터리가 유일한 시계. "돌아갈 수 있을 때 돌아가라" 압박 |
| EA 업데이트 1 | 평야 | **밤이 처음 온다.** 등불버섯·숲·거점 방어 |
| EA 업데이트 2 | 절벽 | 최심부·MARSO |
| 1.0 | 전 구역 | 코어 복원 결말 |

부유섬은 "밤이 없어 밋밋한 곳"이 아니라 **"아직 밤을 모르는 곳"** 이다. EA 업데이트마다 새 시스템이 하나씩 들어오는 구조를 설정이 이미 정해 두었다.

## 6. 단계

각 단계는 **독립적인 스펙 → 플랜 → 구현 사이클**을 갖는다. 전체를 한 스펙에 담지 않는다.

| # | 단계 | 만들 것 | EA 필수 |
|---|---|---|---|
| **P0** | 아트 방향 확립 | 구역별 팔레트·포그·조명 규칙, 머티리얼 통일 레이어, 실루엣 규칙, **물과 매크로늄 두 액체의 시각 구분** | ✅ |
| **P1** | 챕터 1 마감 | 모듈 건축 완결, 화톳불=밝은 곳 승격, 진행 중 작업 정리 | ✅ |
| **P2** | 깊이 게이팅 코어 | 환경 위협(어둠 강도·유독·수심), **섬 간 이동 장비 티어**(수영→다리→액면 보행), 자원 티어, 왕복 압박 리듬, **부유섬 군도 확장** | ✅ |
| **P3** | 생물 3계층 | 기계 생물 모듈 조립 시스템, 소비자 AI, 구역별 종 배치, **도감 공백 채우기**(대형 생산자·포식자 3종 — §4.6) | ✅ (부유섬 분량) |

| (상시) | 코옵 대비 | 권위 소유 모델을 P2부터 코딩 규칙으로 | — |

### 순서의 근거

- **P0가 먼저인 이유**: 가장 싸고, 나중에 하면 가장 비싸다. 이후 모든 에셋이 이 규칙을 통과해야 하며, EA 스크린샷과 트레일러가 전부 여기서 나온다
- **P1이 P2보다 먼저인 이유**: 모듈 건축이 이미 반쯤 만들어져 있다. 열어두면 계속 샌다
- **P2가 P3보다 먼저인 이유**: 생물은 환경 위협 위에 얹힌다. 환경이 없으면 생물이 유일한 위협이 되어 아트 부담이 정면으로 드러난다
- **P4가 EA 이후인 이유**: 밤·숲·등불버섯은 평야의 콘텐츠다. 부유섬 EA에 넣을 수 없고, 넣으면 설정이 깨진다

### 원문 확인 규칙

이 문서의 초판은 `Plan/*.pdf` 원문을 읽지 않고 선행 설계 문서의 요약만 보고 작성했다가, 부유섬이 액체층 위에 떠 있다는 사실을 놓쳐 P2를 잘못 잡았다(§4.3).

**단계별 스펙을 쓰기 전에 해당 구역의 `Plan/*.pdf` 원문을 직접 읽는다.** 요약본을 근거로 삼지 않는다. 추출 방법은 `python -c "import pypdf; ..."` — 저장소에서 동작이 확인되었다.
