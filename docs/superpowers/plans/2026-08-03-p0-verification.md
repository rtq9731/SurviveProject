### StartScene — 사람 판단 필요 (고치지 않고 기록만 한다)

프롤로그 씬은 네 가지가 겹쳐 쌓였다: 환경광 색 `#C4703A`(주황), 안개 `#C4703A` 동일 색 Exp² 밀도 0.035, Volume의 `colorFilter`도 같은 주황(초록을 44%, 파랑을 23%로 곱함), 거기에 `postExposure +0.9`. 샷 4~6에서 실제로 확인한 결과, 화면 전체가 거의 단색 주황/적갈색으로 나온다 — 바위와 안개와 모래폭풍 입자가 색상만으로는 구분되지 않고 명암(실루엣)으로만 겨우 갈린다. 샷 6(모래폭풍 발생기 근접)에서도 입자가 흩날리는 결은 희미하게 보이지만, 입자 색과 배경 안개색이 거의 같아 "모래폭풍이 분다"보다는 "화면이 주황으로 눌렸다"에 더 가깝게 읽힌다. **이 스택을 그대로 둘지 조정할지는 사람이 볼 것 — 고치지 않았다.**

### 보이는 것

**성공한 것**
- **어둠이 실제로 생겼다.** 화면 위쪽 절반이 검정에 가깝다. **다만 이 어둠의 원인을 다시 확인해 보니 `ambientIntensity` 1.05 → 0.15가 아니었다.** MainScene의 `m_AmbientMode`는 3(Flat/색상)인데, Unity는 Ambient Intensity 배율을 Skybox 모드에서만 적용한다. Play Mode에서 `ambientIntensity`를 0.15 → 5(33배)로 올리고 모든 로컬 라이트를 끈 채 스크린샷을 비교했더니 픽셀 평균 밝기가 8~11%밖에 안 움직였다 — 노이즈 수준이지 33배에 해당하는 변화가 아니다. 실제 어둠은 환경광 **색**이 `(0.17, 0.185, 0.235)` → `(0.047, 0.059, 0.082)`로 약 3.6배 어두워진 것에서 전부 나왔다. `ambientIntensity` 수치 자체는 사실상 죽은 노브였다
- **밝은 곳과 어두운 곳의 대비가 생겼다.** 시작 지점 지면이 밝고 그 밖이 어둡다 — P0의 목표였다
- **물이 빛나지 않는다.** 반사만 하고 자체 발광이 없다. 스펙 §4 그대로다
- **발광 버섯이 청록으로 읽힌다.** 광원 체계에서 의도한 색이다
- **저폴리 실루엣이 어둠에서 살아난다.** 샷 3의 부유섬 밑면이 형태만으로 읽힌다

**성공하지 못한 것 — 사람 판단 필요**
- **빛기둥의 기둥이 보이지 않는다.** 바닥의 빛 웅덩이만 보인다. 샷 2에서 위를 올려다보면 **완전한 검정**이다 — 구멍도, 공중의 빛줄기도 없다
  - 원인: 일반 스폿 라이트 + 거리 포그 조합으로는 공중에 빛이 보이지 않는다. 진짜 빛줄기를 만들려면 볼류메트릭 포그나 그것을 흉내내는 원뿔 메시가 필요하다
  - Task 7 검토자가 커밋 전에 정확히 이것을 예측했고("포그만으로는 빛기둥이 안 보일 것이다, 육안으로 확인하라"), 확인해보니 맞았다
  - **스펙 §10과 플랜이 "EA 첫 스크린샷 후보"라고 쓴 것은 현재 사실이 아니다.** 지금은 바닥의 밝은 원이다
  - 설계 의도 중 **"밝기의 근거"와 "랜드마크"는 달성**됐고, **"올려다보면 보이는데 갈 수 없는 곳"은 미달성**이다

| 질문 | 답 |
|---|---|
| 랜턴 없이 초반 탐색이 가능한가 | |
| 밝은 곳이 특별하게 느껴지는가 | |
| 네 광원이 헷갈리지 않는가 | |
| 빛기둥에 실제 빛줄기를 넣을 것인가 (§2 참조) | |

**너무 어둡다면**: `ambientMode`가 Flat인 한 `RenderSettings.ambientIntensity`는 실측상 효과가 없다(위 §2 참조) — 이 값을 돌리는 것은 죽은 노브를 돌리는 것과 같다. 대신 조정할 것은 **환경광 색의 밝기(명도)**다 — `ambientLight`(=`ambientSkyColor`)의 RGB를 같은 비율로 스케일해 밝고 어둡게 조절한다(예: 현재 `(0.047, 0.059, 0.082)`를 균등하게 키우거나 줄인다). `fogDensity`(현재 0.018)도 함께 조정 가능하다. **색상값의 색상환(hue)은 건드리지 않는다** — 명도만 조절하고 채도·색상은 스펙 §4·§6에서 정한 그대로 유지한다. 밝기 문제를 색으로 덮는 것이 게이트 C1에서 한 실수다.
